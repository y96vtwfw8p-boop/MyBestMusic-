Инструкция по добавлению на главный экран

Для iOS (iPhone / Safari)

  1. Откройте сайт в стандартном браузере Safari.
  2. Нажмите на иконку «Поделиться» (квадрат со стрелочкой вверх внизу).
  3. Выберите пункт «На экран „Домой“» (Add to Home Screen).
  4. Нажмите «Добавить» в правом верхнем углу.

Для Android (Chrome / Яндекс)

  1. Откройте сайт в Chrome.
  2. Нажмите на три точки (меню) в правом верхнем углу.
  3. Выберите «Добавить на главный экран» или «Установить приложение».
  4. Подтвердите действие.
